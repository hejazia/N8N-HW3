در این نمونه یک دکمه ساده با متن «ثبت اطلاعات» با استفاده از کامپوننت Button دیزاین سیستم دیگ پیاده‌سازی شده است.

نام دقیق کامپوننت استفاده‌شده: `Button`

علت انتخاب:
- کامپوننت Button دیگ برای ساخت دکمه‌های اکشن با حالات بصری و اندازه‌های مختلف بهینه شده است و به طور کامل از راست به چپ (RTL) و یکپارچگی بصری پشتیبانی می‌کند. سریع، دسترس‌پذیر و استاندارد دیزاین سیستم را تضمین می‌کند.

آیکون‌ها: هیچ آیکونی استفاده نشده است چون نیاز نبود.

نحوه آماده‌سازی و اجرا:
1. نصب کامپوننت button دیگ در پروژه:

```
npx digdesign@latest add https://docs.digdesign.ir/r/button.json
```

2. اطمینان از وجود وابستگی‌های زیر در پروژه:
- class-variance-authority
- clsx
- tailwind-merge

در صورت نبود هر یک از این‌ها:
```
yarn add class-variance-authority clsx tailwind-merge
```
یا
```
npm install class-variance-authority clsx tailwind-merge
```

3. سپس فایل ارائه شده را در پروژه خود (مثلاً src/RegisterButton.tsx) قرار دهید و استفاده کنید.

محدودیت‌ها و منابع:
- کامپوننت Button به صورت کامل از @/components/ui/button وارد می‌شود.
- مستندات رسمی و جدول پراپ‌های قابل استفاده در [مستندات دیگ برای Button](https://docs.digdesign.ir/docs/components/button) موجود است.

همه اطلاعات مربوط به پراپ‌ها از MCP دیگ واکشی شده، و هیچ نام، پراپ یا وابستگی افزوده جَعل نشده است.
