این نمونه یک کارت محصول با دکمهٔ افزودن به سبد خرید و آیکون واقعی سبد خرید دیگچه را ارائه می‌دهد.

### اجزا و منابع بکاررفته
- **ProductCard** (کارت محصول)، **Button** (دکمه) از دیزاین سیستم دیگ
  - ماژول‌ها: `@/components/ui/product-card` و `@/components/ui/button`
  - دستور نصب:
    ```bash
    npx digdesign@latest add https://docs.digdesign.ir/r/product-card.json https://docs.digdesign.ir/r/button.json
    ```
  - منبع: [مستندات کارت محصول در دیگ](https://docs.digdesign.ir/components/product-card)
- **آیکون سبد خرید**
  - نام آیکون: `shopping-cart` (Linear)
  - دریافت‌شده از Digche MCP، به صورت SVG واقعی در کد JSX درج شده است.
  - هیچ وابستگی اضافی برای آیکون لازم نیست.

### نحوه استفاده و اجرا
1. ابتدا کامپوننت‌های موردنیاز این کارت را با دستور بالا نصب کنید.
2. فایل نمونه (`src/ProductCardWithCart.tsx`) را به پروژه خود بیفزایید و در محل دلخواه ایمپورت کنید.
3. دمو Next.js، فایل `src/app/page.tsx` را هم برای پیش‌نمایش سریع آماده کرده‌ایم.

### نکات و محدودیت‌ها
- آیکون سبد خرید تنها از طریق Digche تأیید شده و با کد SVG واقعی است.
- برای نمایش صحیح RTL، Next.js خود را با App Router اجرا نمایید.
- تصویر محصول در نمونه آدرس فرضی `/bag.jpg` دارد؛ برای پروژه خودتان عکس مناسب درج کنید.
- هیچ prop یا API ساختگی در کد وجود ندارد و تمام مقادیری که استفاده شده‌اند مطابق راهنمای MCP دیگ هستند.

### منابع و اعتبارسنجی
- همه APIها و اسامی بر اساس MCP و مستندات دیگ دریافت‌شده‌اند.
- هیچ وابستگی بیرونی برای نمایش آیکون لازم نیست؛ SVG بطور مستقیم در کد آورده شده است.
