### دکمه پرداخت با آیکون کارت اعتباری (Button with Credit Card Icon)

در این نمونه یک دکمه پرداخت با آیکون مناسب با ترکیب کامپوننت کاملاً واقعی دیگ ایجاد شده است:

- **کامپوننت اصلی:** Button از `@/components/ui/button` (طبق مستندات [دکمه دیگ](https://docs.digdesign.ir/components/button)). 
- **آیکون:** «Credit Card» با نام دقیق slug: `credit-card` و سبک `Linear` که مستقیماً از سرویس MCP دیگچه گرفته شده و درون JSX با React-compatible SVG درج شده است. انتخاب این آیکون به علت دقت عملکرد با کلید پرداخت و ارتباط آن با امور مالی بوده است.
- آیکونِ استفاده‌شده وابستگی اضافی ندارد و به صورت inline JSX درج شده؛ بنابراین هیچ پکیج جداگانه‌ای لازم نیست نصب شود.

#### نصب و راه‌اندازی

۱. ابتدا بسته‌ی Button دیگ را نصب کنید:

```sh
npx digdesign@latest add https://docs.digdesign.ir/r/button.json
```

۲. کد نمونه را در پروژه React خود کپی و استفاده کنید.

##### توجه:  
آیکون به صورت JSX کد شده و نیاز به import یا asset جدا ندارد. برای پروژه‌های RTL کاملاً سازگار است و متن «پرداخت» سمت راست و آیکون سمت چپ قرار می‌گیرد (native فارغ از جهت).

##### منابع و مستندات
- Button: [مستندات کامل دیگ](https://docs.digdesign.ir/components/button)
- آیکون Credit Card: [دیگچه - credit-card](https://icons.digdesign.ir/icon/credit-card)

### محدودیت‌ها
- جایگذاری آیکون صرفا inline است (مطابق توصیه مستندات دیگ برای دکمه‌های آیکون‌دار).
- بسته رسمی دیگچه برای import مستقیم آیکون موجود نیست؛ فقط کد SVG استفاده می‌شود.
- هیچ وابستگی مخفی یا موک نشده استفاده نشده است؛ تمام props مطابق با API رسمی Button می‌باشد.
